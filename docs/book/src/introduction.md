# Introduction

This is the project's public documentation surface (an [mdBook](https://rust-lang.github.io/mdBook/)).
It is intended to become the comprehensive outward description of what this project does and
why.

Keep it in lockstep with the code: whenever a slice changes a user-facing command, workflow,
or behavior the book already covers, update the relevant chapter in the SAME commit
(`COMMIT.md`). Curate it — don't dump raw notes here — but don't under-document important
behavior in the name of curation.

> Replace this page and grow `SUMMARY.md` as the project takes shape. Build locally with
> `make book` (requires `mdbook`).
