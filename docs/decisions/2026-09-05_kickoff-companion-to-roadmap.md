# KICKOFF.md is the Phase 0 companion to ROADMAP.md

- **Type:** `decision`
- **Date:** `2026-09-05`
- **Status:** `active`
- **Owner / source:** director clarification during session start; leaf `RB-SEED.1`
answers: how do ROADMAP.md and KICKOFF.md relate; which file is the Phase 0 day-to-day task board?

## The fact / decision

`KICKOFF.md` is associated with `ROADMAP.md` as its Phase 0 companion. They are
one pair, not two competing roadmaps.

## Why

The v0.4.1 master roadmap is the frozen architecture, scope, and gate authority
(`ROADMAP.md` §20.1.2). It is too large to be a daily task board. `KICKOFF.md`
is the immediate execution document for Phase 0: kill-risk questions, work
packages WP0–WP8, repository shape, and the first fifteen issues.

## How to apply

- Treat a change to one as a change that must stay consistent with the other.
- Scope, architecture, and gates: `ROADMAP.md`.
- Phase 0 day-to-day execution: `KICKOFF.md`, owned in task-trees under `PHASE-0`.
- Do not invent a third “real” roadmap file. Parking-lot ideas go to
  `docs/parking-lot.md` (created in Phase 0 WP0), not back into either companion.
