# Roadmap v0.4.1 is frozen until Phase 0 and Phase 1 evidence exist

- **Type:** `decision`
- **Date:** `2026-09-05`
- **Status:** `active`
- **Owner / source:** ROADMAP.md v0.4.1 execution-baseline errata; leaf `RB-SEED.1`

## The fact / decision

`ROADMAP.md` document version 0.4.1 is the frozen execution baseline.
Roadmap v0.5.0 is forbidden until the Phase 0 evidence package and a working
Phase 1 LAN vertical slice exist.

## Why

Pre-code architecture expansion was the failure mode of the Concord
predecessors. v0.4.1 already records the errata that must constrain
implementation. Further features and speculative refinements belong in a
parking lot unless they correct a security defect, a factual error, or a
Phase 0 blocker.

## How to apply

- Pre-code edits to `ROADMAP.md` after v0.4.1: factual errata, security
  corrections, and discovered Phase 0 blockers only.
- New features and speculative refinements: `docs/parking-lot.md` with a
  revisit trigger.
- v0.5.0 must cite measurements, failure observations, or implementation
  constraints produced by working code. Model-to-model review alone cannot
  trigger it.
