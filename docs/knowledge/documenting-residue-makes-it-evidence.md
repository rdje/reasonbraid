# Documenting residue makes it evidence

- **Type:** `knowledge`
- **Date:** `2026-09-22`
- **Owner / source:** leaf `SIGNOFF-REPAIR.11.4.3.1.9.1`, where the three stray clusters the previous leaf had measured at **0** tracked citations reported **2** hours later — and both were that leaf's own record

## The question

A cleanup instrument keeps a directory because *no tracked file may name it*.
You write a finding about that directory: what it is, how big, why nobody owns
it. The next run of the instrument now keeps it for a second reason — your
finding names it. Did the rule just break?

## The answer

> **No. The rule fired exactly as designed, and the cost is real anyway: a
> report about an artefact is indistinguishable, to a name-matching guard, from
> evidence produced by it.**
> Writing residue down converts it into cited evidence, and a guard that
> protects cited evidence will then protect the residue.

⛔ **Do not loosen the guard to escape your own record.** The rule *a retained
artefact a task tree cites by name is evidence* is what stops a sweep deleting
the thing a closed leaf points at, and it cannot tell a citation that says
*this is the proof* from one that says *this is the rubbish*. Narrowing it to
exclude "reports" would need the guard to classify prose, which is the
judgement-over-prose failure this project rejects gates for.

⛔ **And do not silently stop naming the artefact.** The precedent when a
doctrine flags its own description is to RE-WORD rather than exclude — that is
how `POSITIONAL-REF` and `STORAGE-LOCALITY` both came to police themselves. It
does not transfer here: the artefact's NAME is the finding's content, so
re-wording deletes the finding rather than rephrasing it.

⭐ **The remedy is a declared limit, not a mechanism.** State, in the record
that creates the citation, that the citation is this lane's own and that the
guard's refusal is therefore not independent evidence of value. A later reader
deciding the artefact's fate can then discount it. The cost of the honest
version is one sentence; the cost of the quiet version is a permanent keep that
looks like a verdict.

## How to apply it

1. Before writing residue into a tracked document, check whether a cleanup
   instrument keys on tracked citations. If it does, expect the count to move.
2. Write the finding anyway — an unnamed artefact is one nobody can dispose of
   either.
3. In the same record, say that the citation originated here, so the guard's
   later refusal is not read as an independent judgement.
4. If the artefact is eventually to go, the disposition must name the citation
   it is overriding and remove the record and the bytes together.

## What this is not

- ⛔ Not an argument that citation guards are wrong. The founding case for one
  is a sweep that deleted a closed leaf's verification log.
- ⛔ Not a licence to delete something because "the only citation is mine". The
  guard still cannot prove the bytes are unowned; that proof comes from the
  artefact's own receipt, not from the citation count.
