- `crates/reasonbraid-core/` — the domain-model crate (`KICKOFF.md` §3): strong identifiers, command/event envelopes, minimal thread/participation/provider-attempt state machines, and typed errors + the §9.8 reason-code registry landed (WP1 complete). Entry point `src/lib.rs`; envelopes in `src/envelope.rs` (golden fixtures/schemas under `fixtures/` and `schema/`); lifecycles in `src/state.rs`; errors in `src/error.rs`. Owner: repo-local workflow.
- `crates/reasonbraid-server/` — the control-plane crate (`KICKOFF.md` §3), landed in WP2 and extended in WP3 `.3.2`: `.2.1` `apply_command` writes idempotency + event + state + outbox in one PostgreSQL transaction (claim-first idempotency); `.2.2` the leased outbox worker (`src/outbox.rs`: `claim_ready`/`deliver`/`complete`, each phase its own commit, per-claim fencing token + caller-supplied lease clock); `.3.2` the node channel (`src/node_channel.rs`: durable per-node inbox with a monotonic cursor, replay from the node's reported cursor, deduplicated node-event receipts, handshake directives, axum routes over `/v1/nodes/*`). Schema at repository-root `migrations/` (0001 atomic transaction, 0002 worker columns + dedupe sink, 0003 node inbox/events); proof via `scripts/run_pg_tests.sh` (ephemeral server) and the `pg-tests` CI job (all three suites); the general HTTP/SSE command surface is a later leaf. Owner: repo-local workflow.
- `crates/reasonbraid-node/` — the Rust node crate (`KICKOFF.md` §3), landed in WP3: `.3.1` the SQLite node journal (`src/journal.rs` — WAL + `synchronous=FULL` verified at open and recorded in `journal_meta`; boundary-before-boundary ordering: `record_dispatch` commits before the adapter runs; `recover` → honest `outcome_unknown`, `prove_result`/`reconcile` exits; command/operation dedupe, `attempt_transitions` boundary ledger, outgoing events + ack cursor; schema embedded at `migrations/`) and the read-only `rb-journal` inspection CLI (`src/bin/rb-journal.rs`); `.3.2` the outbound channel client (`src/channel.rs`, HTTP/1 JSON over loopback) and the lifecycle facade (`src/node.rs`: `Offline → Reconciling → Schedulable` — schedulable only after the reconnect handshake is fully applied). Kill-point (KP-1…KP-9) and CLI tests run in plain `cargo test` (file-based SQLite); the cross-crate channel tests run in the `pg-tests` job. The execution supervisor and adapter boundary are WP4. Owner: repo-local workflow.
